# Focus Stack

Focus Stack is an offline Android app for keeping your place. Capture a thought into Inbox without leaving the active task, keep a small number of open tasks in Today, and unwind nested interruptions back to the exact task you paused.

There is no account or backend. Speaking a title uses the phone's speech recognizer, prefers an offline pack, and may use the network only when that pack is missing. Elapsed time is computed from stored timestamps while the screen is open.

Coding agents and contributors: read [AGENTS.md](AGENTS.md) for the UI, behavior, testing, and git rules before changing code.

## Requirements

- JDK 21
- Android SDK platform 37.2 and build-tools 37.0.0

Point the SDK at the project with `ANDROID_HOME` or `sdk.dir` in `local.properties`.

## Build and test

```bash
./gradlew test
./gradlew assembleDebug
```

The debug APK is written to `app/build/outputs/apk/debug/app-debug.apk`.

Install that APK on a device or emulator running Android 8.0 (API 26) or newer.

## What the MVP does

Home shows one Now card and a Today list capped by the setting (1 to 5, default 3). A free place is a single dashed empty slot. Inbox and Later are not pulled in to fill it. Inbox, Later, Scheduled, and Done are count rows under Today. Tapping a row opens that pile on its own screen, and Back returns to Today. Those lists stay off Home. Capture stays on Home: a title field with a mic, and saved phrases as chips above it. Tapping the mic asks for the microphone if needed, listens once, and adds the words to the title. It does not save by itself. If speech is unavailable or the microphone is denied, the sheet says so. A line you type can go to Inbox, Today, Start, Interrupt now while a task is in focus, Later, or a date. A phrase chip does not save on its own. A phrase with angle brackets, such as `Talk to <name>`, asks only for that word first. An empty fill-in creates nothing. Then it asks, in one step, Inbox, Today, Start, Interrupt (only while a task is in focus), Later, or Schedule. Inbox leaves the active task alone. Today places it without starting. Start starts it, and if something is already active that is a switch: the current task pauses and this one starts, not nested. If Today is full, Today and Start use the existing choice: Interrupt the current task, or Replace one into Later without starting the new one. Later parks it. Schedule offers Tomorrow, In 7 days, or Pick a date, which opens a calendar with past days disabled. The back arrow at the top left of the sheet steps back one step, and on the first step it closes the sheet; the system back does the same. A picked date can also take a time with Add a time. It does not repeat. The task waits on the Scheduled screen, with its title and date, and its time when one is set, such as `Thu, Oct 8 · 14:30`. It can move early to Today, Start, Inbox, or Later, or be removed. When the date arrives, and the time has passed if one was set, it moves onto Today without starting, if a slot is free. A full Today leaves it scheduled and marked due until a slot opens. The check runs when the app opens and on inexact WorkManager. A task with a time also queues one inexact WorkManager check for that moment, so it can arrive a few minutes late. There are no exact alarms. The existing Today notice can refresh once the task is actually on Today.

The Now card offers Done and Interrupt as actions, with Later quieter. Interrupt opens capture; entering a title and choosing Interrupt now pushes a frame. On a Today task, swipe left to move it to Later. Swipe right is Done when that row is Now, Start when nothing is in focus, and Interrupt when another task is current. That Interrupt pauses the current task and starts this one on top of it. Both stay in Today. Finishing the new one brings back the one underneath, with its return note. A row waiting to be resumed keeps Done, so resume stays explicit. On a Later, Inbox, or Scheduled task, swipe right for Today and swipe left for Start. While a task is in focus, an Interrupt button on the row pauses that task and starts this one nested under it. The return note stays on the paused task. Finishing the interruption brings the parent back. The chosen task leaves that pile, a schedule is cleared, and it does not take a Today slot, so a full Today stays full and nothing is bumped. The button is hidden when nothing is started and when the only open frame is waiting to resume. Today and Start still use the full-Today choice when a slot is required. A slide moves the task and leaves the pile screen open. Done and Later are not offered there. Done and Later commit immediately, with no Undo snackbar. A finished task stays in Done. Opening Done shows that list, and Restore puts the task back into Inbox as an open task without starting it, moving it into Today, or asking to confirm.

The Countdown tab, between Focus and Settings, counts local days to events, nearest first: `12 days`, `Tomorrow`, or `Today`. Add countdown opens a sheet with a title field, the mic, and the same calendar. Each row can change its date or be removed. A countdown never takes a Today slot. On the event day, outside quiet hours, the event comes into focus when the app opens or on the inexact periodic check. If a task is active, it pauses with its return note and the event nests on top as an interruption. If nothing is active, the event just starts. Only one countdown is in the stack at a time; the next one due waits until that one leaves. One silent, dismissible notice says it arrived and opens Focus. The Now card marks it `EVENT` in lavender, with Done, Today, Later, and Count down again. Each one closes the event and leaves the paused task waiting for Resume. Today places the event without starting it, and a full Today asks which task to replace. Later parks it. Count down again picks a new day and puts it back on the Countdown tab. Leaving it running is the same as starting it.

Long-press a Today task and drag to reorder that list. A drop stays inside Today and does not change the bucket. Inbox and Later cannot be dragged onto Today, and Today cannot be dragged onto them.

If Today is already full, adding or starting a task from Inbox or Later does not add a slot. The choice is Interrupt current task, when something in Today is active, or Replace a Today task. Interrupt reuses the incoming task as the new Now, leaves the previous Now recoverable as the parent frame, and moves that previous task out of Today. Replace parks the chosen task in Later and puts the incoming task in that slot, in one transaction, without starting it. If nothing is active, only Replace is available. Adding, swapping, and reordering Today can still offer Undo. Interrupt does not.

Settings stores the Today cap on this phone, a short phrase list, and can turn nudges Off or to about 30 minutes, 1 hour, or 2 hours, set quiet hours, and show an ongoing notice while Today has an open task. With nothing in focus, the notice is titled Today, the collapsed line says how many tasks are open, and a small status icon can show so it stays findable. While a task is active or waiting, the title is that task and the text is the return note. It stays silent either way: no sound, no vibration, and no heads-up. It leaves only when Today is empty, the setting is off, or notifications are denied. Expanding that notice lists each open Today task on its own row, with space and a divider between rows, up to the saved limit. While a task is in focus, that row is marked and opens Focus, and each other row switches to that task: the current one pauses and the chosen one starts, without nesting an interruption. The Interrupt action is on the notice only then. When nothing is started, and when the only frame is waiting to resume, that action is hidden. Tapping an unstarted row while nothing is in focus starts that task, again without nesting. A row that is waiting to resume still opens Focus. Tapping the collapsed notice still opens Focus. The first launch seeds `Talk to my wife` and `Talk to <name>`. Deleting or renaming those examples sticks. Elapsed time stays in the app. Nudges use inexact WorkManager and can be delayed. The app does not use exact alarms or a foreground service. Notification permission is requested only when you turn a notification feature on. If you deny it, capture, Home, and recovery keep working.
